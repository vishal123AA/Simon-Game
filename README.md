# 🔴🟢 Simon Game 🔵🟡

A web-based recreation of the classic electronic memory game, "Simon". This project tests the player's memory by generating a random sequence of colors and sounds that gets longer and faster with each successful round. 

## 🎮 How to Play

1. Press any key (or tap the screen) to start the game.
2. The game will flash a single color.
3. Click the color to repeat the pattern.
4. If you are correct, the game will add another color to the sequence and move you to the next level.
5. Repeat the exact sequence from the beginning.
6. Make a mistake, and it's Game Over! 

## ✨ Features

*   **Dynamic Leveling:** The game progressively increases in difficulty as the pattern grows longer.
*   **Visual Feedback:** Each button press is accompanied by  a visual flash to enhance the memory experience.
*   **Error Detection:** Instantly detects incorrect inputs and triggers a "Game Over" animation.
*   **Responsive Design:** Playable on both desktop and mobile devices.

## 🛠️ Tech Stack

*   **HTML5:** Structuring the game board and buttons.
*   **CSS3:** Styling, layout, animations, and responsive design.
*   **JavaScript (ES6):** Game logic, sequence generation, event listeners, and DOM manipulation.
